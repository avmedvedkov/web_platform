# МНПЦЛИ · Автоматическое распознавание энтеробиоза

Веб-приложение для детекции энтеробиоза (*Enterobius vermicularis*) на микроскопических изображениях с помощью YOLO‑модели.

## Возможности

- Пакетная обработка слайдов (до 7 стёкол в партии)
- Визуализация всех сканов с наложенными рамками и уровнем уверенности
- Полноэкранный просмотр с масштабированием и автоматическим центрированием на объекте
- Очередь ручной проверки с быстрыми клавишами (`Y` — подтвердить, `N` — отклонить)
- Статистика по партии и отдельному слайду
- Генерация миниатюр с кешированием

## Структура проекта

```
enterobiasis_mnptcli/
├── config.py          # настройки: пути, идентификаторы слайдов, параметры модели
├── model.py           # загрузка YOLO‑модели
├── processing.py      # инференс и сбор статистики по партии
├── api.py             # FastAPI приложение с маршрутами и бизнес-логикой
├── main.py            # точка входа: инициализация, обработка, запуск сервера
├── static/            # фронтенд (HTML-интерфейс, favicon)

│   └── favicon.svg

│   ├── Стекло 2/
│   └── ...
├── models/            # файлы весов YOLO (PyTorch / Core ML)

```

## Требования

- Python 3.10 или выше
- Зависимости из `requirements.txt`
- Модель YOLO (`.pt` или `.mlpackage`) в папке `models/`

## Быстрый старт

1. **Создайте и активируйте виртуальное окружение**:

   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / macOS
   venv\Scripts\activate         # Windows
   ```

2. **Установите зависимости**:

   ```bash
   pip install -r requirements.txt
   ```

3. **Подготовьте данные**:

   - Поместите изображения слайдов в папки `scans/Стекло 1/`, `scans/Стекло 2/` и т.д.
   - Поместите файл модели в `models/` (по умолчанию ожидается `best.mlpackage`).

4. **Запустите приложение**:

   ```bash
   python main.py
   ```

   Сервер стартует на `http://0.0.0.0:8000`.

5. **Откройте в браузере** адрес `http://localhost:8000`.

## Конфигурация

Все основные параметры вынесены в `config.py`. Пример содержимого:

```python
SCANS_DIR = "scans"
SLIDE_IDS = ["Стекло 1", "Стекло 2", ...]
MODEL_PATH = "models/best.mlpackage"
IMGSZ = 320
HOST = "0.0.0.0"
PORT = 8000
```

При необходимости измените эти значения до запуска.

## API

| Метод | URL                                   | Описание                                              |
|-------|---------------------------------------|-------------------------------------------------------|
| GET   | `/`                                   | Веб-интерфейс                                         |
| GET   | `/api/slides`                         | Получить данные всех слайдов (сканы и статистика)     |
| GET   | `/api/stats`                          | Общая статистика обработки партии                     |
| GET   | `/thumbnails/{slide}/{filename}?size=120` | Миниатюра заданного размера (в пикселях)          |
| POST  | `/api/review`                         | Обновить статус проверки скана                        |
